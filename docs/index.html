agent-playbooks

One portable rulebook for AI coding agents — built on the AGENTS.md standard, works with Claude Code, Cursor, Antigravity, Gemini CLI, Devin CLI, Factory Droid, Grok Build, Kimi Code, OpenCode, Pi, Hermes Agent, and GitHub Copilot.

View on GitHub ▶ Watch the demo

Why

Every AI coding tool wants instructions in its own format and location. agent-playbooks is one generic instruction set instead — write the rules once, point every tool at the same source of truth. 35 playbooks cover reproducing and fixing bugs, test-first feature development, code review, security review, frontend/backend testing, safe database migrations, incident response, and running an agent against a standing autonomous mission — each one independently verified against a real test case, not just written and published.

Install

curl -fsSL https://raw.githubusercontent.com/chiragmangaldev3112/agent-playbooks/main/install.sh -o install.sh
chmod +x install.sh
./install.sh /path/to/your/project

No account, no token, no cloud dependency — see the full README for per-tool setup and every playbook's index.
